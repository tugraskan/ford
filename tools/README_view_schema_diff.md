# Schema Diff Viewer

A tool to display side-by-side diffs of the `compare_inputs_schema_diffs.csv` file in a human-readable format.

## Overview

The `view_schema_diff.py` script parses the `compare_inputs_schema_diffs.csv` file (generated by `compare_inputs.py`) and displays schema differences in a readable side-by-side format. It supports both terminal and HTML output.

## Usage

### Basic Usage (Terminal Output)

Display the first few diffs:
```bash
python3 tools/view_schema_diff.py --max-rows 10
```

Display all diffs (can be very long):
```bash
python3 tools/view_schema_diff.py
```

### Filter Options

Filter by input file:
```bash
python3 tools/view_schema_diff.py --filter-file "aqu_catunit.def"
```

Filter by component:
```bash
python3 tools/view_schema_diff.py --filter-component "titldum"
```

Combine filters:
```bash
python3 tools/view_schema_diff.py --filter-file "aqu_catunit.def" --filter-component "mreg"
```

### HTML Output

Generate an HTML file for better visualization in a browser:
```bash
python3 tools/view_schema_diff.py --output-html schema_diffs.html
```

Generate filtered HTML output:
```bash
python3 tools/view_schema_diff.py --filter-file "aqu_catunit.def" --output-html aqu_catunit_diffs.html
```

### Other Options

Show unchanged fields (not just differences):
```bash
python3 tools/view_schema_diff.py --show-unchanged --max-rows 5
```

Disable colored output (useful for piping to files):
```bash
python3 tools/view_schema_diff.py --no-color > diffs.txt
```

Use a different CSV file:
```bash
python3 tools/view_schema_diff.py path/to/other_schema_diffs.csv
```

## Output Format

### Terminal Output

The terminal output uses ANSI colors to highlight differences:
- **Red**: Removed fields or old values
- **Green**: Added fields or new values
- **Yellow**: Changed values indicator
- **Cyan**: Field names with changes

Each diff block shows:
- File name, line number, position, and component name
- Side-by-side comparison of old and new values
- Change indicators (ADDED, REMOVED, CHANGED)

### HTML Output

The HTML output provides a cleaner, more professional view with:
- Color-coded differences using background colors
- Organized in collapsible sections
- Better formatting for long values
- Easy to share with others
- Can be opened in any web browser

## Examples

### Quick preview of first 10 changes:
```bash
python3 tools/view_schema_diff.py --max-rows 10
```

### Generate full HTML report:
```bash
python3 tools/view_schema_diff.py --output-html compare_inputs_schema_diffs_sidebyside.html
```

### View changes for a specific file:
```bash
python3 tools/view_schema_diff.py --filter-file "aquifer.aqu"
```

## Files

- `view_schema_diff.py`: Main script
- `compare_inputs_schema_diffs.csv`: Input CSV file (generated by `compare_inputs.py`)
- `compare_inputs_schema_diffs_sidebyside.html`: HTML output file (generated by this script)

## Requirements

- Python 3.6+
- No external dependencies (uses only standard library)
